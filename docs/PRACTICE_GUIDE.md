# Practising the shapes through heart and body

Begin with Circle, or return to a shape that helps you examine a current experience. Every shape is available. The aim is to apply its operation through both exercises with increasing clarity.

## One visit

1. **Read the shape.** State its operation in ordinary words. Read the four prompts for the exercise you chose.
2. **Choose an exercise.** Heart-Coherence moves from heart-focused attention to inviting a sincere feeling of care and staying with it. Body-Sensation Mapping cycles through seven dimensions of a sensation. A faint, absent or uncertain feeling is an acceptable observation.
3. **Keep breathing comfortable.** My own rhythm is the default. The optional cue is five seconds in and five seconds out, without holds. There is no requirement to complete a thought within one breath or to intensify a sensation. Sound is optional and initially off.
4. **Make a return.** Pause when useful. Notice the present observation, recall an earlier one before looking at its note, compare a stated feature or relation, and identify what needs revising. Do this mentally or use the optional note form.
5. **Review your understanding.** Use the shape's checklist and mark your own readiness for this exercise if appropriate. Try the same shape in the other exercise. Both readiness marks are reversible; the timer cannot award either one.

The available timer lengths retain the source exercise: heart practice offers 15, 30, 60, 120 or 180 minutes; body mapping offers 15, 30 or 60 minutes. These are options, not minimum requirements. Pause or end whenever you choose. Hidden pages pause the exercise. A reload does not restore an active timer.

## What each shape adds

| Shape | Operation | Question for either exercise |
| --- | --- | --- |
| Circle | Notice | Can I return to one actual feature without explaining it away? |
| Half-circle | Bind | Which observation belongs to this label and mental address? |
| Triangle | Connect | What relation connects the earlier observation with this one? |
| Square | Return | Am I comparing with the exact observation I intended to retrieve? |
| Pentagon | Contextualise | Does a change of context alter this comparison? |
| Hexagon | Organise | What was the cue, my response and the observed result? |
| Triangular prism | Map | Which roles correspond across two episodes, and where does the analogy fail? |
| Heptagon | Abstract | What provisional function fits these episodes, under which conditions? |
| Octagon | Transfer | Does that function apply in another setting, and what does it predict? |
| Cube | Coordinate | Can I keep expectation, goal, action and outcome distinct in two accounts? |
| Dodecahedron | Retrieve | Which remembered function fits these conditions and limits? |
| Icosahedron | Differentiate | What observation could distinguish the competing explanations? |
| Geodesic sphere | Repair | Which particular step in noticing, retrieving or relating needs correction? |
| Sphere | Integrate | Which operations are useful here, and how should later evidence revise the model? |

Use a simpler shape when it makes a relation clearer. Increasing shape complexity and increasing return distance are separate choices.

## The body-mapping sequence

The seven dimensions are **location, quality, intensity, movement, direction, coherence and meaning-tone**. Each lasts 30 seconds before the next; after meaning-tone the sequence repeats. Dimension buttons let you reread a prompt without changing the timer's sequence. Pause if you need more time.

Intensity is a personal sensation rating, not a score. Coherence asks whether sensation, image, impulse and emotional tone seem aligned; it is not a measured heart state. Meaning-tone stays provisional: a bodily location or texture does not identify one particular emotion.

## Keep an inspectable return

In the optional form, N counts deliberately kept observations within the same shape, exercise and current stream. Extra breaths do not change that position. Start with one observation back; the form permits one through four. The first N observations create history before there is a target at that lag.

Describe the present observation before revealing the earlier source. Recall first, including “I do not recall” when appropriate. Reveal to compare with the original wording, then add your relation and revision. Revealing locks the current observation and recollection. A saved entry cannot be rewritten; make a new entry to preserve a later correction. A fresh stream resets the working return history while keeping earlier saved observations in the record.

You may compare memories and models across the two exercises mentally. The form's exact-lag reference remains within its own shape and exercise stream; it is not a cross-exercise search tool.

## Keep your work

The practice-record download contains all current committed notes, session records and self-assessments, including private text. It excludes unfinished drafts and a running timer. There is no import for current training records. Save or copy drafts before reloading; they are kept only in the open page, even though navigation within that page preserves them.

At 500 observations or 500 recorded practice periods, export before clearing the current record if you want to begin again. Clearing asks for confirmation and does not clear the earlier archive. If storage or conflict warnings appear, export this tab's record before leaving. Keep the original recovery download as well when saved data cannot be read.
